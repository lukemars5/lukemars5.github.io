BreakoutSFML

This game was the first of three projects in the Programming 2D Games module in my first year. I developed the game using SFML and C++. Like the original, the game consists of a paddle controlled by the player and a row of bricks the player must try and destroy. If the player destroys the full wall, then a new wall is generated, making the game endless.

Each brick is worth 60 points, but their value is spread across their health. So for example, a red block starts off with 4 health and hitting a ball that was originally red will grant the player 15 points each hit until the brick is destroyed. Each health value has an associated colour. However, sometimes a brick can become faded, which means any ball phases through it and the brick cannot be destroyed. It can become faded after 10-20 seconds but will return to normal after 2.5-5 seconds.

Space Invaders

This game was the second project in the Programming 2D Games module. I developed the game using Unity and C#. Like the original, the game consists of a spaceship controlled by the player and an army of aliens the player must try and destroy. The game has multiple levels in the form of planets, if the player beats a level they will have the option of unlocking a new weapon or gaining an extra life.

Each planet has a difficulty level, this value determines the enemies' firing rate. As the player kills more enemies, the enemies begin moving faster and firing more often. The player can use bunkers as cover from enemy attacks, but the bunkers have limited health and can be damaged by both the player and the enemies. The mothership is the boss enemy of each level, it has a lot of health and fires missiles at the player, but it moves slighly slower than the other enemies.

TwinStickZ

This game was the main project in the Object Oriented C++ Programming module in my second year. I developed the game using DirectX 11 and C++. The game features endless waves of zombies that will attempt to kill the player. The game offers a variety of upgrades, including a minigun, speed boost and insta-kill.

The player has control of a pistol which has 17 bullets per magazine, if the player reloads with bullets still in the magazine, then there will be an extra bullet in the magazine. The zombies have a randomised health value between 75 and 150, and bullets deal less damage the further they travel, which makes the player think more about their positioning.
